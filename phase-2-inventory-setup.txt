RFN ADMIN PHASE 2 — SUPABASE STOCK / INVENTORY

WHAT IS CONNECTED
- Inventory reads all products from public.products.
- +1 and -1 update products.stock_quantity in Supabase.
- Editing a product saves stock, prices, name and bike to Supabase.
- Every stock change creates a row in public.inventory_logs.
- Completing an order calls set_order_status and deducts stock once.
- Cancelling a completed order restores stock once.
- Admin API access requires an authenticated Supabase user that exists in public.admin_users with active=true.

1) SUPABASE SQL

  supabase/RFN-Supabase-ALL-IN-ONE.sql
